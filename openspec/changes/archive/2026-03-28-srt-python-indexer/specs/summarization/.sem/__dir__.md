This directory contains the specification for the summarization component of the SRT (Semantic Resolution Tree) Python indexer system. It defines how the indexer should generate natural-language summaries for files and directories using LLM calls. The specification covers implementation details like oversized file handling, LLM provider interfaces, and error handling strategies.
