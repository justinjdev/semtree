This directory contains the command-line interface specification for the SRT (Semantic Resolution Tree) Python indexer project. The specifications define requirements for a `semtree` CLI tool that builds and maintains semantic summary hierarchies for code repositories. This is part of an archived OpenSpec change from March 28, 2026, focused on implementing the Python-based indexer component of the SRT system.

## Children

- **spec.md**: CLI specification document defining requirements for the `semtree` indexer tool, including the core `build` command, model selection options, token limits, force rebuild capabilities, and error handling scenarios for constructing Semantic Resolution Trees in repositories.
